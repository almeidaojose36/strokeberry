# Strokeberry app walkthrough

A 60-second vertical walkthrough of the real app, using guided closeups of captured screens and a real exported drawing video.

0–10 seconds: New project, select the tutorial image, see it appear in the app.
10–20 seconds: Choose Ink, enable pencil and color, then select 9:16 portrait and HD quality.
20–34 seconds: Review the 2 × 2 crops, confirm the reading order, and set each stage to 15 seconds before preparing.
34–43 seconds: Review the preview timeline and stages. The result excerpt is shown at 4× speed.
43–54 seconds: Export video, wait for rendering, then Download MP4.
54–60 seconds: Strokeberry mascot and closing message.

Format: 1080 × 1920, 30 fps, silent master with English instructions. Add platform-licensed music when posting if desired.
