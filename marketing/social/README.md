# Strokeberry social assets

Rendered files are in `out/`. To change the wording or artwork, edit `template.html` and run `scripts/render-social.sh` (needs Google Chrome).

| File | Where it goes | Size |
|---|---|---|
| `profile-sun.png` | Profile picture on every platform (recommended: stands out in feeds) | 1080×1080 |
| `profile-cream.png` | Alternative profile picture | 1080×1080 |
| `youtube-banner.png` | YouTube → Customize channel → Branding → Banner | 2560×1440 |
| `x-header.png` | X → Edit profile → Header | 1500×500 |
| `facebook-cover.png` | Facebook Page → Edit cover photo | 1640×624 |
| `linkedin-company-cover.png` | LinkedIn Page → Edit page → Cover image | 1128×191 |
| `pinterest-cover.png` | Pinterest business profile → Edit profile → Cover | 1920×1080 |
| `highlight-*.png` | Instagram story highlight covers (Gallery, Tutorials, Tips, New) | 1080×1920 |

Instagram and TikTok have no banner; use the profile picture, plus the highlight covers on Instagram.

Each banner keeps its text and artwork inside the area every device shows, clear of the profile photo and of mobile or TV cropping.
